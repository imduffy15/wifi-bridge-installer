Put any wired device on Wi-Fi

WiFi Bridge turns a WT32-ETH01 or another ESP32 Ethernet board into a bridge between your Wi-Fi network and the board's Ethernet port. Printers, NAS devices, game consoles, and other wired-only devices join your Wi-Fi network without new cables.

This browser can't install firmware. The installer needs Web Serial, which desktop Chrome, Edge, and Opera support. Open this page in one of those browsers.
This page can't access serial ports. Open it over HTTPS or from localhost.

Connect the board over USB first (see the steps below). Then click Install and choose its serial port. On a first install, select Erase device.

What it does

The bridge connects one wired device on one side to your Wi-Fi network on the other.

Wi-Fi to Ethernet

The bridge joins your Wi-Fi network as a client and forwards traffic to and from the device plugged into its Ethernet port.

Same network, same addresses

The wired device gets its IP address from your router, and other devices on your network can reach it like any other client.

Web setup and updates

Set up Wi-Fi from your phone or laptop, check the bridge's status, and install firmware updates from your browser without a cable.

Install

You need a computer with desktop Chrome, Edge, or Opera, and a USB cable or USB-serial adapter. Installing takes a few minutes.

  1. Connect the board

    Boards with USB (Olimex, ESP32-Ethernet-Kit): Plug the board into your computer. The installer puts it into download mode for you.

    Olimex ESP32-POE (non-ISO): Don't power the board from PoE while it's connected to your computer by USB. Only the ISO variant is electrically isolated.

    WT32-ETH01 has no USB port. Connect a USB-serial adapter set to 3.3 V logic:

    AdapterWT32-ETH01
    TXRX0
    RXTX0
    GNDGND
    5V5V (or 3.3 V to 3V3, if the adapter can supply 500 mA)
    GND (jumper)IO0, held to GND while the board starts or resets

    The ESP32 enters its bootloader only if IO0 is low at reset. Connect IO0 to GND, and then turn on the board (or briefly connect EN to GND). Leave the jumper in place until the installation finishes.

  2. Click Install

    At the top of this page, click Install WiFi Bridge and choose the serial port (often CP2102, CH340, or FT232). If the port isn't listed, install the driver for your adapter. On Linux, add your user to the dialout group.

  3. Erase and install

    On a first install, or when you replace other firmware, select Erase device. This removes old settings that could interfere with the bridge. Installing takes about a minute.

  4. Restart the board

    On a WT32-ETH01, remove the IO0 jumper and turn the board off and on again (or briefly connect EN to GND). Boards with USB restart automatically.

Set up the bridge

If you didn't enter your Wi-Fi network in the installer, connect to the bridge in one of these ways.

Over Wi-Fi

From a phone or laptop, join the setup network wifi-bridge-xxxxxx. The suffix comes from the board's MAC address (its hardware address). The setup page opens automatically. If it doesn't, go to http://192.168.4.1.

Over Ethernet

Plug a computer into the board's Ethernet port. The computer gets an address automatically. To open the same setup page, go to http://192.168.5.1.

Then

Choose your Wi-Fi network, enter its password, and accept the suggested management address: the fixed IP address of the bridge's page. If your board isn't a WT32-ETH01, choose it on the Ethernet tab afterward. Plug in the wired device, and it appears on your network.

Update and troubleshoot

Which file should I use?
  • wifi-bridge-<version>.ota.bin: The application only. Use this file for firmware updates. Install it on the Firmware tab of the bridge's page, or from the safeboot firmware.
  • wifi-bridge-<version>.safeboot.bin: The safeboot firmware, a small recovery firmware for boards with a single firmware slot. Install it once on the Firmware tab of the bridge's page.
  • wifi-bridge-<version>.factory.bin: The complete image (bootloader, partition table, and application), flashed at offset 0x0 over serial. This page installs it for you.
  • wifi-bridge-<version>.elf (on the GitHub release): Debug symbols for decoding crash backtraces.
Install from the command line

Install esptool, put the board in download mode, and run:

esptool.py --chip esp32 write_flash 0x0 wifi-bridge-<version>.factory.bin

To start from an empty flash, run erase_flash as a separate command first.

The installer can't connect to the board
  • Check that TX and RX are crossed: adapter TX to board RX0.
  • WT32-ETH01: Make sure that IO0 was connected to GND before the reset, and that the adapter uses 3.3 V logic.
  • Close other programs that use the port, such as a serial monitor or another browser tab.
  • Try a shorter cable or a different USB port. Power the board from 5 V instead of the adapter's 3.3 V pin.
